Loaded immediately.loadLazy(): Below-the-fold content—standard blocks, footer, images loaded lazily.loadDelayed(): Non-critical third-party scripts (e.g., Google Analytics, Chatbots, MarTech tags) deferred by 3 seconds to preserve Core Web Vitals.Pillar 2: Block Engineering & Metadata MechanicsBlock Variants: Creating styled variations of blocks using CSS class modifiers (e.g., .cards.compact or .hero.dark).Section Metadata: Using special section-metadata tables in documents to apply background colors, grid layouts, or style themes to entire page sections.Page Metadata: Using metadata tables to set og:image, og:title, canonical URLs, and robots indexing rules.Auto-Blocking: Writing JavaScript logic inside scripts.js to automatically convert plain links (like YouTube or Vimeo URLs) into responsive interactive blocks without the author manually creating a table.Pillar 3: Site Administration & UtilitiesRedirects (redirects.xlsx / .csv): Managing 301/302 redirects at the CDN edge via spreadsheets without writing server-side rules.Custom Headers (headers.json): Setting HTTP headers (CORS, Cache-Control, Security Headers) per folder path.Placeholders (placeholders.xlsx): Storing multi-language UI strings (e.g., "Submit", "Search", "Read More") managed through spreadsheets and accessed via fetchPlaceholders().Pillar 4: Performance & Analytics (RUM & Sidekick)Real User Monitoring (sampleRUM()): How EDS measures real-world Lighthouse, LCP, INP, and CLS scores without heavy third-party scripts.Sidekick Customization (/tools/sidekick/config.json): Adding custom buttons, environments, and quick-action tools to the Adobe Sidekick browser extension.3. Hands-On Projects You Can Do (NO Universal Editor or Sandbox Required!)You do not need Universal Editor or an AEM Sandbox program to become a master EDS developer. Everything below can be built 100% locally using VS Code, aem up, GitHub, and Google Drive or SharePoint.Hands-On Exercise 1: Build a Custom Block with CSS VariantsObjective:Build an Accordion Block with a .accordion.faq variant.Steps:Create a new folder in your repository: /blocks/accordion/.Create two files:accordion.jsaccordion.cssWrite the transformation logic in accordion.js:JavaScriptexport default function decorate(block) {
  [...block.children].forEach((row) => {
    const [header, body] = row.children;

    const title = document.createElement('summary');
    title.append(...header.childNodes);

    const content = document.createElement('div');
    content.append(...body.childNodes);

    const details = document.createElement('details');
    details.append(title, content);

    row.replaceWith(details);
  });
}

  const links = main.querySelectorAll('a[href*="youtube.com"], a[href*="youtu.be"]');
  links.forEach((link) => {
    if (link.origin === link.textContent.trim()) {
      const embedBlock = buildBlock('embed', [[link.cloneNode(true)]]);
      link.replaceWith(embedBlock);
    }
  });
}
